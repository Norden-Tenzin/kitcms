# @kitcms/ui

The kitcms admin: the shell, dashboard, list and edit views, the field components, the block editor, the upload field and the media library. It is Svelte 5 and is rendered by a route file that `kitcms` generates into your app, so there is nothing to build by hand. The admin logic (`load` and form `actions`) lives in `@kitcms/core/sveltekit/admin`.

```sh
pnpm add @kitcms/ui
```

`@kitcms/ui` peer-depends on `@kitcms/core`, `@sveltejs/kit` (v3) and `svelte` (v5).

## Usage

The admin route in an app is generated, and should not be edited. `templates/blank/src/routes/(kitcms)/admin/[...path]/+page.svelte`:

```svelte
<!-- GENERATED by kitcms. Do not edit: the admin lives in @kitcms/ui. -->
<script lang="ts">
	import { Admin } from '@kitcms/ui';

	let { data, form } = $props();
</script>

<Admin {data} {form} />
```

The matching `+page.server.ts` re-exports the server side:

```ts
// GENERATED by kitcms. Do not edit: the admin lives in @kitcms/core and @kitcms/ui.
export { load, actions } from '@kitcms/core/sveltekit/admin';
```

## Exports

From `packages/ui/src/lib/index.ts`:

- `Admin`: the admin app component. The generated route renders it.
- `FieldShell`: the wrapper that field components render inside.
- `fieldId`: builds the DOM id for a field.
- `FieldProps` (type): the props every field component receives.
- `getFormContext`: reads the form context inside a field component.
- `FormContext` (type): the shape of that form context.
- `FileUpload`: the upload control.
- `MediaPicker`: the media library picker used by the upload and relationship fields.
